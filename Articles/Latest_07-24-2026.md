## 3. DeepSeek Retires Legacy API Aliases Today (15:59 UTC)

**Source:** [Enterprise DNA — DeepSeek API Migration July 24 Deadline](https://enterprisedna.co/resources/news/deepseek-api-migration-july-24-deadline-2026/) | [Developers Digest](https://www.developersdigest.tech/blog/deepseek-chat-to-v4-migration-guide)

As of 15:59 UTC today, DeepSeek's `deepseek-chat` and `deepseek-reasoner` API aliases are permanently retired. Any application still using those legacy model names will receive errors. Developers must migrate to the explicit V4 model IDs: `deepseek-v4-flash` (non-thinking) and `deepseek-v4-pro` (reasoning). The deadline had been set since the V4 preview launched on April 24, giving teams three months to update integrations.
