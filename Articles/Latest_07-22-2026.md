## 2. Kimi K3: The World's Largest Open-Weight AI Model Arrives

**Source:** [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/moonshot-releases-2-8-trillion-parameter-kimi-k3) | [Interconnects.ai](https://www.interconnects.ai/p/kimi-k3-the-open-weights-escalation) | [HuggingFace Blog](https://huggingface.co/blog/ResterChed/kimi-k3-model-overview-mxfp4-quantization-open-wei)

Moonshot AI's **Kimi K3** is a 2.8-trillion-parameter Mixture-of-Experts model — the largest open-weight model ever released. It launched via Kimi's apps and API on July 16, with full open weights dropping on **July 27**. The model features a 1-million-token context window, always-on thinking mode, and supports text, image, and video inputs. In benchmarks it ranks 4th among all frontier models, trailing only Claude Fable 5 and GPT-5.6 Sol — and claimed the #1 spot in the Frontend Code Arena (1,679 points). Pricing is $3/M input and $15/M output tokens. Its open-weight release is seen as a significant escalation by Chinese AI labs working around U.S. compute restrictions.
